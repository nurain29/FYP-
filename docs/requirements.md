# Requirements

## Functional requirements
1. The system shall allow customer to fill the complaints website form.
2. The system shall process each complaints human-text using Natural Language Processing (NLP)
3. The system shall do the classification for each complaints into categories like billing, internet connectivity, customer service.
4. The system shall allow staff to view their complaint details and categories.
5. The system shall staff to update a complaints status.
6. The system shall store all the complaints and their classification results for other management process.

## Non-functional requirements 
1. The system shall display a classification result within 5 seconds after the complaints reach the system.
2. The system shall allow a customer to submit their problem text into no more than 5 required input space.
3. The system shall require authorized staff to log in before manage comlaints records.
4. The system shall display an error message if compaints is unsuccessfully updates.
