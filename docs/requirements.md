# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow customer to fill the complaints website form.
2. The system shall analyse complaints text using Natural Language Processing (NLP)
3. The system shall classify complaints into categories like billing, internet connectivity, customer service.
4. The system shall assign each complaints their priorities to low, medium or high based on its rules.
5. The system shall allow staff to see their complaint details, categories and suggested priority levels.
6. The system shall staff ti update a complaints status.
7. The system shall store all the complaints and their classification results for next management process.

## Non-functional requirements (how the system must PERFORM)
1. The system shall display a classification result within 5 seconds after the complaints reach the system.
2. The system shall allow a customer to submit their problem text into no more than 5 required input space.
3. The system shall require authorized staff to log in before manage comlaints records.
4. The system shall display an error message if compaints is unsuccessfully updates.
