# User Stories


1. As a user, I want to submit a complaint through website form, so that I can report any problem with service I received.(FR1)
    Acceptance Critereia:
    1. Given all the required field is filled, when customer submits complaint, then the system will save the complaint.
    2. Given field is empty, when customer submits form, then the system will display error message.

2. As a customer sevice staff, I want to classify each complaints text into categories, so that i can identify the type of problem for each complaint easily.(F2,F3)
    Acceptance Critereia:
    1. Given complaint that has beed submitted, when NLP process is completed, then the system process each category
    2. Given that the complaint has been categorized, when staff view the complaint, then the category shall display for each complaint. 
    
3. As a staff, I want to see the priority for each complaint, so taht I can decide best solution for urgent cases.(F4,F5)
    Acceptance Criteria: 
    1. Given that a complaint has been received, whan prioritization process has been done, then the system will display priority level such as low, medium, and high.
    2.Given that a complaints priority has been displayed, when staff view the complaint has been processed, then they will be able to view details complaint and suggested priority.
